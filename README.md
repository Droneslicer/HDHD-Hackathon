# HDHD-Hackathon

Basic hackathon repository scaffold with common folders and starter files.

## Structure

```text
.
├── assets/
├── data/
│   ├── processed/
│   └── raw/
├── docs/
├── notebooks/
├── scripts/
├── src/
└── tests/
```

## Quick Start

1. Put source code in `/src`.
2. Put experiments in `/notebooks`.
3. Put scripts/automation in `/scripts`.
4. Keep docs in `/docs`.
5. Keep tests in `/tests`.
6. Keep datasets in `/data/raw` and cleaned outputs in `/data/processed`.
